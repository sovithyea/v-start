# v-start — product

What Vith has confirmed, kept separate from what is still open or assumed. Nothing moves to Confirmed without Vith saying so.

## Confirmed

- A Claude Code plugin that starts any project with a proven agent harness and personalises it to the person and the project.
- Users: anyone who uses Claude Code (public).

- Three commands (`/v-start`, `/v-discover`, `/v-spec`) plus the bundled skills; personalisation for both the person and the project (D003).
- Done for the first version: a friend installs it, runs `/v-start`, and gets a working harness without help.
- What matters most: get it right. No deadline.

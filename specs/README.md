# Specs

One folder per piece of work: `specs/N-name/`. Each holds a `spec.md` (why, the belief it tests and its pass mark, what's there today, what changes, how we know it's done; 1–3 pages) and a `plan.md` (checkbox steps). **No code starts until Vith approves both.**

`0-example/` is the template. Copy it, renumber it, and delete it once the first real spec exists.
